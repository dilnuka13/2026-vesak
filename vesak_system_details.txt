මෙම ලේඛනය මඟින් වත්මන් ව්‍යාපෘතියේ (2026-vesak-main) සියලුම තාක්ෂණික තොරතුරු, ලිපිගොනු ව්‍යුහය (File Structure), දත්ත ගබඩා වගු (Database Tables), ලොජික් (Logic), සින්ටැක්ස් (Syntax) සහ සැලසුම් අංග (Design Aesthetics) සවිස්තරාත්මකව දක්වයි. 

අවසානයේ මෙම පද්ධතිය නැවත මුල සිටම නිර්මාණය කිරීමට අවශ්‍ය සම්පූර්ණ AI Prompt එක ද ඇතුළත් කර ඇත.

  ├── admin.html                - පරිපාලන උපකරණ පුවරුව (Admin Dashboard - React UMD, Supabase integration, CRUD, Analytics, Session Management, PDF/CSV Reports)
  ├── view_income.html          - පොදු ආදායම් සහ සම්මාදම් සෙවුම් පෝටලය (Dynamic Receipt PDF/Canvas generator)
  ├── invitation.html           - වෙසක් උත්සව ආරාධනා පත්‍රය (Countdown, Calendar, Google Map)
  ├── maintenance.html          - නඩත්තු පිටුව (පොදු පිවිසුම අක්‍රීය කර ඇති විට පෙන්වයි)
  ├── offline.html              - අන්තර්ජාලය නොමැති විට පෙන්වන පිටුව
  ├── 404.html                  - 404 පිටුව
  ├── logo.png                  - වෙසක් පද්ධති ලාංඡනය (Vesak System Logo)
  ├── poson_logo.png            - පොසොන් පද්ධති ලාංඡනය (Poson System Logo)
  ├── ve1rify.png               - Verified ලකුණ සහිත මුද්‍රාව (Verification Stamp)
  ├── dc.png                    - ධර්ම චක්‍රය සහිත ලාංඡනය (Dharma Chakra Corner Wheel)
  ├── favicon.svg               - Favicon අයිකනය
  ├── icons.svg                 - SVG අයිකන ගොනුව
  ├── setup_sessions.sql        - පරිශීලක සෙෂන්ස් සැකසුම් SQL
  ├── Vesak_Backup_2026-05-14.sql - දත්ත සමුදායේ (Database) SQL බැකප් එක (INSERT ප්‍රකාශන)
  ├── manifest.json             - PWA Manifest ගොනුව
  ├── js-section-access-control.js - ප්‍රවේශ පාලන Logic (හිස් ලිපිගොනුවක්)

  │   ├── index.html            - පොසොන් ප්‍රධාන පිවිසුම් පිටුව (Amber/Gold තේමාව සහිතව)
  │   ├── view_income.html      - පොසොන් පොදු ආදායම් සෙවුම් පෝටලය

---
2. දත්ත සමුදා වගු සහ තීරු (Database Tables & Columns - Supabase / PostgreSQL)
---
පද්ධතියේ පසුබිම් දත්ත ගබඩාව (Database backend) ලෙස Supabase (PostgreSQL) භාවිතා වේ. පහත දැක්වෙන්නේ වගු (Tables) සහ ඒවායේ තීරු (Columns) වේ:

1. app_users (පද්ධතියේ පරිශීලකයින්)
   - id : UUID (PRIMARY KEY)
   - username : TEXT (පරිශීලක නාමය)
   - password_hash : TEXT (SHA-256 මුරපද කේතය)
   - role : TEXT ('admin' හෝ 'user')
   - is_temp_password : BOOLEAN (තාවකාලික මුරපදයක්ද යන්න)
   - phone_number : TEXT (දුරකථන අංකය)
   - address : TEXT (ලිපිනය)
   - is_contributor : BOOLEAN (දායකයෙක්ද යන්න)
   - two_factor_enabled : BOOLEAN (2FA සක්‍රීයද යන්න)
   - fcm_token : TEXT (FCM Push Notifications සඳහා)
   - avatar_url : TEXT (ඡායාරූපය - Base64 හෝ URL)
   - passkey_id : TEXT (FaceID / Fingerprint / WebAuthn passkey ID)

2. user_sessions (පරිශීලක පිවිසුම් තොරතුරු)
   - id : UUID (PRIMARY KEY)
   - user_id : UUID (FOREIGN KEY -> app_users.id)
   - session_token : TEXT (UNIQUE)
   - device_name : TEXT (උපාංගයේ නම)
   - location : TEXT (පිවිසි ස්ථානය)
   - ip_address : TEXT (IP ලිපිනය)
   - last_active : TIMESTAMPTZ (අවසාන සක්‍රීය වේලාව)
   - is_online : BOOLEAN (සජීවීව පද්ධතියේ සිටීද යන්න)
   - created_at : TIMESTAMPTZ

3. project_settings (ව්‍යාපෘති සැකසුම්)
   - id : TEXT (PRIMARY KEY, e.g., 'global')
   - allow_income_entry : BOOLEAN (ආදායම් ඇතුළත් කිරීමට අවසරය)
   - allow_expense_entry : BOOLEAN (වියදම් ඇතුළත් කිරීමට අවසරය)
   - allow_pledge_entry : BOOLEAN (පොරොන්දු සම්මාදම් ඇතුළත් කිරීමට අවසරය)
   - income_access_list : TEXT (ආදායම් බැලීමට අවසර ඇති පරිශීලකයින්ගේ ලැයිස්තුව)
   - expense_access_list : TEXT (වියදම් බැලීමට අවසර ඇති පරිශීලකයින්ගේ ලැයිස්තුව)
   - pledge_access_list : TEXT (පොරොන්දු බැලීමට අවසර ඇති පරිශීලකයින්ගේ ලැයිස්තුව)

4. incomes (ලැබුණු සහ පොරොන්දු වූ ආදායම්/සම්මාදම්)
   - id : UUID (PRIMARY KEY)
   - date : DATE (දිනය)
   - name : TEXT (දායකයාගේ නම)
   - phone_number : TEXT (දුරකථන අංකය)
   - address : TEXT (ලිපිනය)
   - donation_type : TEXT ('Cash' හෝ 'Goods')
   - amount : NUMERIC (මුදල - donation_type = 'Cash' නම්)
   - donor_category : TEXT (දායක කාණ්ඩය, e.g., 'Main Donor', 'Regular Donor')
   - item_description : TEXT (ද්‍රව්‍යමය පරිත්‍යාග පිළිබඳ විස්තරය - donation_type = 'Goods' නම්)
   - quantity : TEXT (ප්‍රමාණය - donation_type = 'Goods' නම්)
   - status : TEXT ('Received Today', 'Promised')
   - reported_by : TEXT (ඇතුළත් කළ පරිශීලකයා)
   - description : TEXT (අමතර විස්තර)
   - event_type : TEXT ('vesak' හෝ 'poson')
   - created_at : TIMESTAMPTZ

5. expenses (සිදුකළ වියදම්)
   - id : UUID (PRIMARY KEY)
   - reason : TEXT (වියදම් කිරීමට හේතුව)
   - withdrawer_name : TEXT (මුදල් ලබාගත් අයගේ නම්)
   - date : DATE (දිනය)
   - time : TIME (වේලාව)
   - amount_taken : NUMERIC (ලබාගත් මුදල)
   - receipt_url : TEXT (බිල්පතේ රූපය - Supabase Storage RECEIPTS bucket)
   - reported_by : TEXT (ඇතුළත් කළ පරිශීලකයා)
   - event_type : TEXT ('vesak' හෝ 'poson')
   - created_at : TIMESTAMPTZ

6. vesak_invitation / poson_invitation (ආරාධනා පත්‍ර සැකසුම්)
   - id : INTEGER (PRIMARY KEY, e.g., 1)
   - anniversary : TEXT (කීවෙනි වසරද යන්න, e.g., '1')
   - description : TEXT (ආරාධනා විස්තරය)
   - members : TEXT (නිර්මාණ කණ්ඩායමේ සාමාජිකයින්)
   - map_link : TEXT (Google Maps Embed Iframe URL)
   - dates : TEXT (ප්‍රදර්ශන දිනයන් - JSON array string, e.g., '["2026-05-30", "2026-05-31"]')
   - time_start : TEXT (ආරම්භක වේලාව, e.g., '18:30')
   - time_end : TEXT (අවසන් වන වේලාව, e.g., '02:00')
   - gallery_links : TEXT (පෙර නිර්මාණ වීඩියෝ/රූප සබැඳි - JSON string)
   - is_published : BOOLEAN (ප්‍රසිද්ධ කර තිබේද යන්න)

7. notifications (දැනුම්දීම්)
   - id : UUID (PRIMARY KEY)
   - record_id : UUID (අදාළ වාර්තාවේ ID)
   - type : TEXT (කාණ්ඩය)
   - message : TEXT (දැනුම්දීමේ පණිවිඩය)
   - created_at : TIMESTAMPTZ

8. user_passkeys (WebAuthn / FaceID මුරපද රහිත පිවිසුම්)
   - id : UUID (PRIMARY KEY)
   - user_id : UUID (FOREIGN KEY -> app_users.id)
   - passkey_id : TEXT (Passkey ID)
   - passkey_name : TEXT (උපාංගයේ නම)
   - created_at : TIMESTAMPTZ

  - UMD React, Tailwind CSS, Babel භාවිතා කරමින් තනි HTML ලිපිගොනුවක් තුළ සම්පූර්ණ React App එකක් ලෙස ක්‍රියාත්මක වේ.
  - Supabase Auth මඟින් පරිශීලක පිවිසුම පාලනය කරයි.
